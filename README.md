## What Is Adamat?

Adamat gives Dungeon Masters one browser-based place to prepare and run their campaigns. Instead of separating setting references, location maps, NPC notes, character information, and rules tools, the application keeps these resources within a shared campaign workspace.

The project uses Node.js with vanilla JavaScript to provide a focused, lightweight foundation for D&D campaign organization. During preparation or play, DMs can access the information behind their world, party, and game sessions from the same interface.

---

## Capabilities

- **Campaign map workspace** for arranging locations and other visual campaign material.
- **Atlas organization** for collecting setting and world references.
- **NPC records** for creating, storing, and maintaining non-player character details.
- **Character tools** for preparing characters used in a campaign.
- **Integrated rules engine** for consulting and applying D&D rules within the app.
- **Campaign organization** to keep preparation resources together rather than scattered across notes.
- **Web access** through a browser-based application.
- **Node.js plus vanilla JavaScript stack** for a straightforward, lightweight implementation.

## Using Adamat

One possible campaign setup sequence is:

1. Launch Adamat in a compatible modern browser.
2. Set up or open a campaign workspace.
3. Add the maps and atlas references needed for the setting.
4. Enter NPC details in the NPC management section.
5. Prepare the party and other campaign characters.
6. Consult the rules engine while planning encounters or resolving game questions.
7. During play, return to the map, atlas, NPC, character, or rules section you need.

For a hosted instance, open the published application URL. When running the project locally, use the address reported by the configured Node.js server.

## Frequently Asked Questions

### Does Adamat run as a desktop app?

No. Adamat is a web application accessed through a browser, either from a hosted instance or from a local Node.js setup.

### Who is the application for?

Adamat is primarily intended for Dungeon Masters who need to organize D&D campaign resources such as maps, atlas material, NPCs, characters, and rules information.

### What is the update process?

Pull or download the newest project files, install dependency changes, and restart the configured Node.js process. Review the repository updates before applying them to an existing deployment.

### Where do I change configuration settings?

Look through the repository's package manifest, environment files, and application configuration. The available options vary with the current project build.

### What should I do if Adamat will not start?

Check that Node.js is installed and that the project dependencies are present. Confirm the command matches a script listed in the package manifest, make sure the configured port is free, and review terminal output for startup errors.

### Can Adamat be run locally?

Yes. Set up the repository with Node.js, start the local server, and open the server address supplied by the application in a browser.
